# BOYA Website Migration

The product page, bilingual documentation, community, membership, and
account services are now maintained in the private
[BOYA Web repository](https://github.com/DylanChiang-Dev/BOYA-web).

This Astro repository is retained as the historical website source. The
target production entry point is [boya.caiada.edu.kg](https://boya.caiada.edu.kg);
its DNS and production cutover are tracked separately. The former Pages site
remains available as a historical and rollback entry during the transition.
